# ComfyUI-MinuteSaver ⏱

按**系统时间（精确到分钟）**自动分文件夹 / 命名保存**图像**与**视频**的 ComfyUI 自定义节点。

灵感来自 WAS Node Suite 的 `Image Save` 与 VideoHelperSuite 的 `VHS_VideoCombine`
里 `[time(%Y-%m-%d)]` 那套令牌写法 —— 但那个写法只能精确到「天」，而且必须手写
令牌。本节点把「时间」做成了两个独立开关：**文件夹上放什么时间**、**文件名上放什么时间**，
默认就精确到分钟。

## 安装

### 方式一：ComfyUI-Manager（推荐）

搜索 `MinuteSaver` → Install → 重启 ComfyUI。

### 方式二：手动 clone

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/zhang1san2feng3/ComfyUI-MinuteSaver.git
```

重启 ComfyUI 即可，**无需安装任何依赖**：

- 图像保存用 `Pillow`（ComfyUI 自带）
- 视频保存用 `ffmpeg`，按下面顺序自动查找：
  1. 环境变量 `FFMPEG_BINARY`
  2. 系统 `PATH` 里的 `ffmpeg`
  3. `imageio-ffmpeg` 内置的 ffmpeg（装了 VideoHelperSuite 就有）
  4. `C:\ffmpeg\bin\ffmpeg.exe`

  全都没找到时节点会给出明确报错，不会静默失败。

## 两个节点

分类：`MinuteSaver/时间保存`

| 节点 | 类名 | 输入 | 输出 |
|---|---|---|---|
| ⏱ 按时间保存图像 | `MinuteSaveImage` | `IMAGE` | `images` / `完整路径` / `文件夹` |
| ⏱ 按时间保存视频 | `MinuteSaveVideo` | `IMAGE`（+ 可选 `AUDIO`） | `完整路径` / `文件夹` |

图像节点会把 `IMAGE` 原样透传出去，所以可以插在流程中间继续接别的节点。

## 默认输出长什么样

图像（默认参数）：

```
ComfyUI/output/ComfyUI_Image/2026-09-06/ComfyUI_16-13_0001.png
└─ output 根 ─┘└ 二级目录 ──┘└ 日期文件夹 ┘└前缀┘└分钟┘└序号┘
```

视频（默认参数）：

```
ComfyUI/output/MiniMaxH3/2026-09-06/ComfyUI_16-13_00001.mp4
```

- **文件夹**：日期（`%Y-%m-%d`），一天一个文件夹，和你原来 `2026-09-05原始待查` 的习惯一致
- **文件名**：`前缀_分钟_序号`，同一分钟内连续出图共享分钟戳、序号从 `0001` 递增；
  跨到下一分钟自动换名、序号重新从 1 开始

想让文件夹也带分钟？把「文件夹时间格式」改成 `%Y-%m-%d_%H-%M` 即可，
做到**每一分钟一个独立文件夹**：

```
ComfyUI/output/ComfyUI_Image/2026-09-06_16-13/ComfyUI_16-13_0001.png
```

## 时间格式怎么填

「文件夹时间格式」「文件名时间格式」两个字段，**两种写法都认**：

| 写法 | 例子 | 渲染结果 |
|---|---|---|
| 裸 strftime | `%Y-%m-%d` | `2026-09-06` |
| 裸 strftime | `%H-%M` | `16-13` |
| WAS 风格令牌 | `[time(%Y-%m-%d)]` | `2026-09-06` |
| 令牌嵌文字 | `存档[time(%m-%d)]` | `存档09-06` |

> 也就是说，从旧的 `Image Save` / `VHS_VideoCombine` 里复制过来的
> `[time(%Y-%m-%d)]` 可以直接粘进来用。

可用格式符（strftime）：`%Y` 年、`%m` 月、`%d` 日、`%H` 时、`%M` 分、`%S` 秒、
`%j` 年内第几天、`%W` 周数、`%p` AM/PM……

在「文件名前缀」「额外文件名」「输出路径」里还能用这些额外令牌：

| 令牌 | 含义 |
|---|---|
| `[time]` | Unix 时间戳（秒） |
| `[date]` | 等价 `[time(%Y-%m-%d)]` |
| `[hostname]` | 机器名 |
| `[user]` | 当前用户名 |

⚠️ **Windows 文件名不允许 `: * ? " < > |`**，会被自动替换成 `_`。
所以写「时:分」请用 `%H-%M`，**不要**用 `%H:%M`（会变成 `16_13`）。

## 四种保存模式

| 保存模式 | 文件夹 | 文件名 | 结果示例 |
|---|---|---|---|
| `文件夹+文件名`（默认） | ✅ 带时间 | ✅ 带时间 | `ComfyUI_Image/2026-09-06/ComfyUI_16-13_0001.png` |
| `仅文件名` | ❌ | ✅ 带时间 | `ComfyUI_Image/ComfyUI_16-13_0001.png` |
| `仅文件夹` | ✅ 带时间 | ❌ | `ComfyUI_Image/2026-09-06/ComfyUI_0001.png` |
| `都不加(固定名)` | ❌ | ❌ | `ComfyUI_Image/ComfyUI_0001.png` |

## 参数详解

### ⏱ 按时间保存图像 (MinuteSaveImage)

| 参数 | 默认 | 说明 |
|---|---|---|
| `images` | — | 要保存的图像，支持批次（batch 会逐张按序号存） |
| `保存模式` | `文件夹+文件名` | 见上一节 |
| `二级目录` | `ComfyUI_Image` | `output` 下的目录，可留空直接写 `output` 根目录；支持令牌 |
| `文件夹时间格式` | `%Y-%m-%d` | 每天一个文件夹 |
| `文件名前缀` | `ComfyUI` | 支持令牌；留空则用二级目录名 |
| `文件名时间格式` | `%H-%M` | **分钟戳**；清空则文件名只留 `前缀_序号` |
| `文件名分隔符` | `_` | 前缀与时间之间的连接符 |
| `文件名序号位数` | `4` | 补零位数，`0001` |
| `文件名序号起始` | `1` | 起始序号 |
| `图片格式` | `png` | `png` / `jpg` / `webp` |
| `质量` | `95` | `jpg`/`webp` 是压缩质量；`png` 用来换算压缩级别 |
| `重名处理` | `按序号自动递增` | 见下方「重名处理」 |
| `嵌入工作流` | ✅ | 把 prompt / 工作流写进 PNG，拖回 ComfyUI 能还原 |
| `允许绝对路径` | ❌ | 勾选后「输出路径」写绝对路径时直接写到该磁盘目录 |
| `输出路径_覆盖`（可选） | 空 | 留空用「二级目录」；填绝对路径需勾选上一项；填相对路径会作为**追加**子目录 |
| `额外文件名`（可选） | 空 | 接一个字符串，追加到文件名前缀后面（如接角色名 / 系列名） |

**重名处理**

| 选项 | 行为 |
|---|---|
| `按序号自动递增`（默认） | 已存在就往后找一个空号，**永不覆盖** |
| `直接覆盖` | 同名直接覆盖 |
| `允许重名(追加毫秒)` | 同名时追加毫秒时间戳，避免覆盖 |

### ⏱ 按时间保存视频 (MinuteSaveVideo)

| 参数 | 默认 | 说明 |
|---|---|---|
| `images` | — | 图像序列。**批次会自动串成一段视频**（N 张 = N 帧） |
| `帧率` | `24.0` | 写入视频的 fps |
| `视频格式` | `mp4 (h264)` | `mp4` / `mov` / `mkv`（h264）/ `webm`（vp9） |
| `CRF质量` | `19` | 越小越清晰、文件越大；18~20 基本视觉无损 |
| `保存模式` | `文件夹+文件名` | 同上 |
| `二级目录` | `MiniMaxH3` | 同上 |
| `文件夹时间格式` | `%Y-%m-%d` | 同上 |
| `文件名前缀` | `ComfyUI` | 例如填系列名「我的系列示例」 |
| `文件名时间格式` | `%H-%M` | 分钟戳；清空则 `前缀_序号` |
| `文件名序号位数` | `5` | `00001` |
| `文件名序号起始` | `1` | 起始序号 |
| `重名处理` | `按序号自动递增` | 同上 |
| `保存元数据` | ✅ | 把 prompt / 工作流写进视频容器元数据 |
| `允许绝对路径` | ❌ | 同上 |
| `audio`（可选） | — | 接 VAE 解码出的 `AUDIO`，会一起写进 mp4（AAC 192k） |
| `输出路径_覆盖`（可选） | 空 | 同上 |
| `额外文件名`（可选） | 空 | 同上 |

视频输出是 **YUV420P**，浏览器 / 手机 / 剪映通吃；
奇数宽高的输入会自动裁成偶数，不会出现编码失败。

## 常见用法与坑

**1. 想要「每一分钟一个文件夹」**

```
保存模式        = 文件夹+文件名
文件夹时间格式  = %Y-%m-%d_%H-%M
文件名时间格式  = 清空
文件名前缀      = ComfyUI
```
→ `output/ComfyUI_Image/2026-09-06_16-13/ComfyUI_0001.png`

**2. 想保留原来的系列命名**

把「文件名前缀」从 `ComfyUI` 改成你的系列名，例如 `我的系列示例`，
再按需要把「文件名时间格式」清空：

→ `output/MiniMaxH3/2026-09-06/我的系列示例_00896.mp4`

**3. 想彻底不按时间分目录**

「保存模式」选 `都不加(固定名)`，等于一个普通保存节点。

**4. 节点上的「上次保存路径」什么时候更新？**

执行完成后才会显示真实路径。因为路径里的时间是按**执行那一刻**的系统时间算的，
所以在画布上实时预览反而会骗人，这里刻意不做实时推算。
点「📂 复制上次路径」可以把结果复制到剪贴板。

**5. 视频节点报「找不到 ffmpeg」**

装一个 ffmpeg 加进 PATH，或设置环境变量 `FFMPEG_BINARY` 指向 `ffmpeg.exe`；
装了 VideoHelperSuite 的话会自动用它的内置 ffmpeg。

**6. 文件名里想带 `:`**

做不到，Windows 不允许。用 `-` 代替。

## 自检

不启动 ComfyUI 就能跑一遍功能自检（会用你的 Python 真的生成 png/jpg/webp 和一个 mp4）：

```bash
python selftest.py
```

秋叶整合包环境里用：

```bash
E:\ComfyUI-aki-v1.6\python\python.exe selftest.py
```
